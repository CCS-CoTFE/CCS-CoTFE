# Examples

The exhibit is intentionally read as one continuous scroll rather than as separate demo routes.

- Open the local site with `pnpm dev`.
- Scroll through **Idea** to see the claim and headline effect.
- Continue through **Benchmark** to select a causal variable and inspect the active path.
- Continue through **Evidence** to explore benchmark bars, coverage, decomposition, response curves, the evidence matrix, and the full source figures.

The published version is available at <https://ccs-cotfe.github.io/CCS-CoTFE/>.
